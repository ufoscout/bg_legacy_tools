1. Installation

Run setup program. 

2. Basic Operation

I tried to make the interface as user friendly as possible. Everything is on a screen
when you start program. In left panel you got list of modules. When you click on item in
left panel associated editor is loaded and available for using.

There are two cammands in File menu: Open and Save. Save is also available from toolbar thru 
disk icon. When you choose to open a saved game file common Windows file open dialog will appear. 
Then you can find your saved game files and choos one to open. Open option is available only when
there is active editor in right panel. That means you have selected a game from left tree view.
All changes are stored in file imediately after switching to another unit or when you change page.
You can also press disk icon to save unit record.

3. Required files
PSTHack.exe and all modules are written in Borland's Delphi. In order to run program you must have Delphi 
runtime files.

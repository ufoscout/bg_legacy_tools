# Infinity Engine Savegame Editors

This directory collects several savegame/character editors for games built on
BioWare's Infinity Engine. Each folder contains one editor (`Gate Keeper Src` holds the source
code for `Gate Keeper`).

## Editors

| Editor | Folder | Version | Games it can modify |
| --- | --- | --- | --- |
| Gate Keeper | `Gate Keeper` | 1.9.1 | Baldur's Gate · Baldur's Gate - Tales of the Sword Coast |
| Sword Coast Keeper | `Sword Coast Keeper` | 1.0.5 | Baldur's Gate · Baldur's Gate - Tales of the Sword Coast |
| Shadow Keeper | `ShadowKeeper` | 2.1.4 | Baldur's Gate II - Shadows of Amn · Baldur's Gate II - Throne of Bhaal |
| Dale Keeper | `DaleKeeper` | 1.3.4.0 | Icewind Dale |
| Dale Keeper II | `DaleKeeper2-Beta-5` | 2.0 Beta 5 (1.0.0.5) | Icewind Dale II |
| Planescape: Torment Editor (PSTHack) | `PS Torment Hack` | 1.0 | Planescape: Torment |
| Infinity Engine Savegame Editor (IESE) | `IESE1.0.0.9_XP_r21_RT` | 1.0.0.9 (r21) | Baldur's Gate · Baldur's Gate - Tales of the Sword Coast · Baldur's Gate II · Baldur's Gate II - Throne of Bhaal · Icewind Dale (+ Heart of Winter) · Planescape: Torment |
| Enhanced Edition Keeper (EEKeeper) | `EEKeeper 1.0.4.0` | 1.0.4.0 | Baldur's Gate: Enhanced Edition · Baldur's Gate II: Enhanced Edition · Icewind Dale: Enhanced Edition · Planescape: Torment: Enhanced Edition |
